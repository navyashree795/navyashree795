### 🌟 About Me

👋 Hello! I am **Navya Shree S**, an **Electronics and Communication Engineering (ECE)** engineer passionate about building high-performance digital hardware architectures, smart connected IoT ecosystems, and intuitive mobile & web applications.

- 🎓 **Education:** Electronics & Communication Engineering, *Don Bosco Institute of Technology*
- 🔬 **Core Specialization:** VLSI ASIC Design, Digital Logic Synthesis, Cryptographic Hardware Cores (LFSR/NFSR stream ciphers), and Verilog HDL.
- 📱 **Software & Systems:** Cross-platform mobile development with React Native (Expo SDK 54), TypeScript, modern React.js, and Firebase cloud integrations.
- ⚡ **IoT & Embedded:** Real-time sensor telemetry, computer vision edge systems, ESP32/ESP8266 microcontroller automation, and hardware-software co-design.
- 💬 **Ask me about:** Verilog, OpenLane ASIC flows, React Native, Firebase, and IoT architectures.
